**Phở Rush** — a Vietnamese street-food kitchen game. Customers order phở, bánh mì, cơm tấm, bún chả and gỏi cuốn; you grab ingredients from the counter, boil broth, grill meat, chop herbs, assemble the dish on the plate and serve it before the customer's patience runs out. Combos grow your tips, and the last 45 seconds are rush hour.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click to play, or use keys 1–8 for ingredients, Q/W/E for the stations, Space to serve, R to restart.
